# 스토어 자산

| 파일 | 용도 | 규격 |
|---|---|---|
| `icon-512.png` | Play Console 앱 아이콘 | 512×512 PNG, 알파 없음 |

아이콘은 손으로 그리지 않는다. `design/graphics/PodGlyphPath`와 같은 수식으로 뽑아
런처 아이콘·알림 아이콘·배터리 링 안 실루엣과 한 모양을 유지한다. 글리프 비율을
바꿨다면 다시 생성해야 한다 — 생성 스크립트는 커밋 메시지에 남아 있고, 적응형
아이콘의 배치(108 캔버스에 쌍 크기 74)를 그대로 512로 확대한 것이다.

아직 준비하지 않은 것: 스크린샷(최소 2장), 피처 그래픽 1024×500, 짧은 설명,
개인정보처리방침 URL. 이 앱은 어떤 데이터도 기기 밖으로 보내지 않으므로 그 사실을
적은 정적 페이지 한 장이면 된다.
