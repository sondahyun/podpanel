비어 있어도 빌드는 통과합니다 — 다만 바이트 해석이 실기로 검증되지 않은 상태로 남습니다.

앱의 **원시 패킷 보기** 패널에서 hex를 복사하고, 그 순간 눈으로 확인한 값을 같이 적으세요.
모르는 값은 `?`로 두면 그 항목만 건너뜁니다.

```
label = 케이스 열고 양쪽 다 넣음
left  = 80
right = 80
case  = 40
hex   = 07 19 01 14 20 20 88 04 03 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
```

## 무엇을 찍어야 하나

README의 "검증이 필요한 부분" 체크리스트가 그대로 촬영 목록입니다.

| 상황 | 무엇이 밝혀지나 |
|---|---|
| 왼쪽만 착용, 오른쪽은 케이스 | 좌/우 니블 순서 (`FLIP_MASK_SET_MEANS_NORMAL`) |
| 오른쪽만 착용, 왼쪽은 케이스 | 위와 대칭 — 두 개가 같이 있어야 판정된다 |
| 케이스 열기 / 닫기 | 케이스 배터리 보고 조건, `lidOpenCounter` |
| 케이스를 충전기에 연결 | 충전 플래그 비트 위치 |
| 한쪽을 멀리 두고 범위 밖으로 | `0x0F` 미보고 값 |
